# Archive Index

이 폴더는 **활성 개발 문서에서 분리된 이력성 기록**만 보관한다.

## 포함 문서

- `incidents.md`  
  주요 이슈 원인/조치/재발방지 기록

- `sessions/`  
  날짜별 개발 세션 요약 (예외: `streamwriter-notes.md`는 세션이 아닌 레퍼런스성 노트 —
  핵심 내용은 `docs/gpl-language/file-io.md`로 승격됨)

- `reviews/`  
  시점별 프로젝트 리뷰 기록

- `test-robot/`  
  2026-08-18 이관. 지금은 삭제되고 없는 GPL 로봇 애플리케이션 **Test_robot** 시절의
  개발 문서(인수인계서, 구조, 버전 관리, 업로드 자동화). 각 문서 최상단의 폐기 배너 참조.
  현행 문서가 아니므로 따라 하지 말 것.

## 정리 원칙

- 현재 운영/개발의 기준 문서는 `docs/development/`, `docs/reference/`, `docs/gpl-language/`를 우선한다.
- 중복 인덱스, 임포트 흔적 파일, 오래된 안내 README는 보관하지 않는다.
- 아카이브 문서는 “삭제 대신 이관”이 기본이며, 중복만 제거한다.
